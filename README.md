# TradeProof — legal

Public legal pages for the **TradeProof** Android app.

Published with GitHub Pages:

- Privacy policy: <https://archangel-77.github.io/tradeproof-legal/>

## Source of truth

The canonical text lives in the (private) app repository at `docs/privacy-policy.md`. This
repository holds the published copy only: when the policy changes, update it there first, copy it
into `index.md`, and commit with a date bump.

The published page must always agree with the Play Console **Data safety** answers. Anything
about data collection changes in both places at once, never in one.
